# Static assets

| File | Description |
|------|-------------|
| `little-farms-logo.png` | Little Farms circular logo (196×196 PNG). Originally from `https://littlefarms.com/media/favicon/stores/1/LF_Logo_3_1.png` — kept in-repo so the admin UI does not depend on that URL. |

To replace the logo, overwrite `little-farms-logo.png` here **and** copy the same file to `web-src/assets/little-farms-logo.png` (static fallback next to `index.html`), then rebuild the app.
